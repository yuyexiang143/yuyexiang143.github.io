数据清洗与报表自动化

yuyexiang143 / datatoolkit

把「每月手工整理这几张表」变成一条命令。读取 xlsx / xls / csv，统一日期格式、 清洗带 ¥ 和千分位的金额、去重、处理空值、合并多个分区文件，最后输出带汇总和异常清单的 Excel 报表。 原始文件全程只读，不会被覆盖。

Python pandas openpyxl CLI tkinter
14 个测试通过 支持 GBK 编码 CSV 自动识别 命令行 + 图形界面

批量文件处理工具

yuyexiang143 / file-toolkit

几百个文件要改名、按日期归档、转格式、查重复？这个工具一次搞定。 它默认只做预演，把「旧名 → 新名」全部列给你看，确认后才真正执行； 每次执行都留一份回滚清单，改错了能一条命令撤销。

Python Pillow dry-run undo
15 个测试通过 默认不落盘，误操作可撤销 图片 / 文本编码双支持

数据看板生成器

yuyexiang143 / dashboard-gen

给一份 CSV 或 Excel，生成一个单独的 HTML 文件——KPI 卡片、趋势折线、分布图、 可搜索可排序的明细表全在里面。不依赖服务器，不联网也能打开，直接微信发给老板就能看。 图表是内联生成的，没有任何外部 CDN。

Python pandas 内联 SVG 离线可用
11 个测试通过 输出单个 38KB HTML 零外部依赖
